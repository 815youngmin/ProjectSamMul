# ProjectSamMul

서버 없이 로컬에서 실행되는 2D 서바이버류 액션 게임 데모입니다.
이전에 참여했던 모바일 게임 프로젝트에서 **제가 직접 작성한 클라이언트 코드**만 추려내고,
서버·네트워크·유료 에셋·회사 자산에 의존하던 부분은 새로 작성한 오프라인 구현으로 대체했습니다.

> 코드를 처음 보는 분은 [docs/architecture.md](docs/architecture.md)부터 읽으면 전체 구조를 10분 안에 파악할 수 있습니다.

## 작업 방식

이 저장소는 이전 프로젝트의 코드를 **Claude Code(Anthropic)** 의 도움을 받아 옮기고 정리했습니다.
역할은 다음과 같이 나뉩니다.

- **원본 게임플레이 코드** (스테이지, 캐릭터/몬스터 AI, 스킬, 장판, 전투/스탯, 스테이지 이벤트, UI 로직): 제가 이전 프로젝트에서 직접 작성한 코드입니다. 파일 단위로 작성 여부를 확인해 제가 쓴 것만 가져왔습니다.
- **Claude Code와 함께 진행한 작업**: 이관 범위 분석, 회사 자산·서버 의존 코드 제거, 오프라인 세션·`Shared` 데이터 계층·플레이스홀더 애니메이터/리소스 같은 대체 구현 작성, 미사용 코드 정리, 데모용 정적 데이터 작성, 공용 공격 비주얼과 판정 범위 표시, 문서 작성.

## 1차 데모 내용

로비(챕터 · 캐릭터 · 장비를 한 줄씩 라디오 버튼으로 선택) → 스테이지 플레이 (웨이브 생존, 엘리트, 보스전) → 결과 팝업

| 항목 | 내용 |
|---|---|
| 챕터 | 3개 (원시 / 빙하기 / 이집트). 원본 1~3챕터의 스테이지 이벤트·몬스터 데이터를 그대로 사용 |
| 캐릭터 | Tenti, Ignatia, Dice. 각자 고유 기본 공격 스킬 |
| 장비 | D / B / S 등급 3종. 등급이 체력·공격력(+10/20/30%)·이동속도(0/15/30%)를 결정 |
| 스킬 | 16종 (액티브 11, 패시브 5). 레벨업 시 3택1 선택, 스킬 상자, 5레벨 초과 시 초월 |
| 몬스터 | 45종, AI 전략 9종 (근접, 원거리, 돌진, 통과, 독장판, 소환, 반사탄, 사망 폭발, 이동·정지) |
| 보스 | 10종. 이동 3초·정지 1초 패턴, 등장 순서대로 이동 속도 5.0 → 7.25 |
| 시스템 | 경험치·레벨, 아이템 상자(체력·자석·폭탄·골드·스킬 상자), 부활 1회, 일시정지, 결과 팝업 |
| 그래픽 | 몬스터·보스·캐릭터·아이템은 AI 생성 스프라이트. 공격 판정 범위는 도형으로 표시(플레이어 파란색, 적 빨간색). 일부 연출은 플레이스홀더(흰 사각형) |

## 실행 방법

1. Unity **2021.3.45f2** 로 프로젝트를 엽니다.
2. Asset Store에서 **DOTween**을 임포트합니다 (`Assets/Plugins/Demigiant`). 저장소에는 포함되어 있지 않습니다.
3. 메뉴 **Demo → Validate Static Data** 로 데이터 로드를 확인합니다.
4. `Assets/Scenes/Lobby.unity` 를 열고 Play.

씬·한글 폰트·무음 사운드 프리팹은 저장소에 포함되어 있습니다. 다시 만들어야 할 때만 **Demo → Build Scenes / Build Korean Font / Build Sound Prefabs** 메뉴를 사용합니다.

## 설계 메모

- **오프라인 세션**: 원래 서버 프로토콜(챕터 입장/종료/포기/부활)을 같은 호출 형태로 로컬에서 즉시 처리하고 JSON으로 저장합니다.
- **플레이스홀더 리소스**: `ResourcePool` 이 프리팹/스프라이트/스켈레톤 데이터가 없을 때 요청된 컴포넌트를 붙인 오브젝트를 만들고, 직렬화 참조 필드를 리플렉션으로 채워 NullReference 없이 동작하게 합니다. 사운드만 예외로, 없으면 즉시 예외를 던집니다.
- **정적 데이터**: 테이블별 JSON 파일을 Newtonsoft로 읽으며, 없는 테이블은 빈 테이블로 취급합니다.
- **공격 판정 표시**: 전용 이펙트가 없는 스킬은 실제 판정 도형(원·사각·부채꼴)을 `AttackAreaFlashManager` 로 그려 범위를 그대로 보여 줍니다.

## 라이선스

이 저장소의 코드는 포트폴리오 목적으로 공개합니다. 제3자 에셋(DOTween 등)은 각자의 라이선스를 따르며 저장소에 포함하지 않습니다.

로비 아이콘, 몬스터·캐릭터·아이템 스프라이트, BGM 같은 데모용 이미지·음악은 AI 생성 리소스입니다.
한글 서체는 넥슨 메이플스토리 서체를 사용합니다 (`Assets/Fonts/LICENSE-Maplestory.md`).
