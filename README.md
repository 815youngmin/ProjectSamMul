# ProjectSamMul

서버 없이 로컬에서 실행되는 2D 서바이버류 액션 게임 데모입니다.
이전에 참여했던 모바일 게임 프로젝트에서 **제가 직접 작성한 클라이언트 코드**만 추려내고,
서버·네트워크·유료 에셋·회사 자산에 의존하던 부분은 새로 작성한 오프라인 구현으로 대체했습니다.

## 작업 방식

이 저장소는 이전 프로젝트의 코드를 **Claude Code(Anthropic)** 의 도움을 받아 옮기고 정리하는 중입니다.
역할은 다음과 같이 나뉩니다.

- **원본 게임플레이 코드** (스테이지, 캐릭터/몬스터 AI, 스킬, 장판, 전투/스탯, 스테이지 이벤트, UI 로직): 제가 이전 프로젝트에서 직접 작성한 코드입니다. 파일 단위로 작성 여부를 확인해 제가 쓴 것만 가져왔습니다.
- **Claude Code와 함께 진행한 작업**: 이관 범위 분석, 회사 자산·서버 의존 코드 제거, 오프라인 세션·`Shared` 데이터 계층·플레이스홀더 애니메이터/리소스 같은 대체 구현 작성, 미사용 코드 정리, 데모용 정적 데이터 작성.

## 데모 흐름

로비(챕터 · 캐릭터 · 장비를 한 줄씩 라디오 버튼으로 선택) → 스테이지 플레이 (웨이브 생존, 엘리트, 보스전)

- 챕터 3개 (서부 / 스팀펑크 / 아라비안 테마 보스)
- 스킬 40종 (액티브 24, 패시브 16), 레벨업 시 스킬 선택, 초월
- 일반·엘리트 몬스터 AI 전략, 테마별 보스 패턴, 장판·투사체 시스템
- 그래픽은 플레이스홀더(색 사각형)입니다. 리소스가 없으면 런타임에 자동 생성됩니다.

## 구조

| 폴더 | 내용 |
|---|---|
| `Assets/Scripts/GameClients/Stages` | 스테이지 루프, 캐릭터/몬스터, 액션, AI 전략, 스킬, 장판, 투사체, 스테이지 이벤트, 전투/스탯 |
| `Assets/Scripts/GameClients` | 게임 클라이언트, 오프라인 세션(로컬 저장), 카메라 |

## 실행 방법

1. Unity **2021.3.45f2** 로 프로젝트를 엽니다.
2. Asset Store에서 **DOTween**을 임포트합니다 (`Assets/Plugins/Demigiant`). 저장소에는 포함되어 있지 않습니다.
3. 메뉴 **Demo → Build Korean Font** — `Assets/Fonts` 의 넥슨 메이플스토리 서체로 TextMeshPro 한글 폴백 폰트 에셋을 만듭니다 (서체 라이선스: `Assets/Fonts/LICENSE-Maplestory.md`).
4. 메뉴 **Demo → Build Sound Prefabs** — 코드가 참조하는 사운드 프리팹(무음)을 생성합니다. 사운드 프리팹이 없으면 실행 중 예외로 알려줍니다.
5. 메뉴 **Demo → Build Scenes** 로 `Loading / Lobby / Stage` 씬을 생성합니다.
6. 메뉴 **Demo → Validate Static Data** 로 데이터 로드를 확인합니다.
7. `Assets/Scenes/Lobby.unity` 를 열고 Play.

## 설계 메모

- **오프라인 세션**: 원래 서버 프로토콜(챕터 입장/종료/포기/부활)을 같은 호출 형태로 로컬에서 즉시 처리하고 JSON으로 저장합니다.
- **플레이스홀더 리소스**: `ResourcePool` 이 프리팹/스프라이트/스켈레톤 데이터가 없을 때 요청된 컴포넌트를 붙인 오브젝트를 만들고, 직렬화 참조 필드를 리플렉션으로 채워 NullReference 없이 동작하게 합니다.
- **정적 데이터**: 테이블별 JSON 파일을 Newtonsoft로 읽으며, 없는 테이블은 빈 테이블로 취급합니다.

## 라이선스

이 저장소의 코드는 포트폴리오 목적으로 공개합니다. 제3자 에셋(DOTween 등)은 각자의 라이선스를 따르며 저장소에 포함하지 않습니다.
